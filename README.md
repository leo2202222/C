# 🚀 My C Programming Journey

คลังรวมซอร์สโค้ดภาษา C พัฒนาขึ้นในช่วงเริ่มต้นเรียนรู้พื้นฐานการเขียนโปรแกรม (Programming Fundamentals) เพื่อฝึกฝนการใช้เงื่อนไข (If-Else), ลูปวนซ้ำ (Loops), การจัดการโครงสร้างเมนู และการแยกเขียนฟังก์ชันย่อย (Functions)

---

### 📂 โครงสร้างโฟลเดอร์และผลงาน

* 📂 **age-calc** : โปรแกรมจำแนกกลุ่มช่วงอายุ
* 📂 **area-calculator** : โปรแกรมคำนวณพื้นที่ (ฝึกใช้ if-else ซ้อนกัน)
* 📂 **bonus-calc** : โปรแกรมคำนวณเงินเดือนบวกโบนัสตามขั้นบันไดยอดขาย
* 📂 **even-sum-calc** : โปรแกรมหาผลรวมของเลขคู่ $n$ ตัวแรกเริ่มนับจาก 0
* 📂 **factorial-calc** : โปรแกรมคำนวณหาค่า แฟกทอเรียล ($n!$) โดยใช้ลูป `for`
* 📂 **find-min** : โปรแกรมหาค่าน้อยที่สุดจากตัวเลข 3 ตัว
* 📂 **function-menu-calc** / **modular-calculator** : โปรแกรมรวมเมนูคำนวณขั้นสูง แยกโครงสร้างด้วยโมดูลฟังก์ชันย่อย (`summation`, `calArea`, `electronic`)
* 📂 **menu-calculator** / **multi-utility-calc** : โปรแกรมรวมเมนูเช็กเลขคู่คี่, คิดราคาโต๊ะ, และหาค่า Max ทศนิยม
* 📂 **multiplication-table** : โปรแกรมแสดงตารางสูตรคูณแม่ 1-12 ออกทางหน้าจอ
* 📂 **ticket-pricing** : โปรแกรมคิดราคาตั๋วตามส่วนสูง 

---

### 🛠️ วิธีการคอมไพล์และรันโปรเจกต์ (Automated Build)

โปรเจกต์นี้รองรับระบบคอมไพล์อัตโนมัติด้วย **Makefile** สามารถเปิด Terminal ในโฟลเดอร์นี้แล้วสั่งงานได้ทันที:

* **สั่งคอมไพล์โปรแกรม:** พิมพ์คำว่า `make`
* **สั่งรันโปรแกรม:** พิมพ์คำว่า `./multi-utility-calc`
* **ล้างไฟล์ขยะ (.o และตัวรัน):** พิมพ์คำว่า `make clean`
